# Notel for Homebrew

```bash
brew install macprotips/notel/notel
```

This tap installs the same signed, notarized Notel release that is published at
[macprotips/notel-updates](https://github.com/macprotips/notel-updates/releases).
Notel keeps itself up to date with its built-in updater.

Uninstalling (`brew uninstall notel`, with or without `--zap`) removes only the
app. Your notes are never deleted by Homebrew.
